# UX principles

The customer experience must feel **dramatically simpler** than the underlying platform.

## Target checkout flow

```
Browse
→ Product
→ Add to cart
→ Delivery / Pickup
→ Date / time
→ Recipient
→ Customer
→ Card / comment
→ Submit
→ Confirmation / Tracking
```

## Constraints

- No mandatory registration
- Mobile-first
- One clear action per step
- Platform power (CMS, ERP, AI, loyalty) stays behind the scenes

The storefront is live commerce UX (catalog, cart, checkout, legal pages); keep visual changes intentional and brand-consistent.
